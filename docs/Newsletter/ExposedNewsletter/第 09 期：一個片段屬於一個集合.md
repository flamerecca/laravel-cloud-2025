# 一個片段屬於一個集合

你想列出某個集合底下的所有片段，卻只能自己手寫一個條件，再自己確認集合真的存在。

資料之間有從屬關係時，Exposed 希望你在資料表定義的時候，就把這個關係說清楚。說清楚之後，兩個方向的讀取都會輕鬆很多。

## 關聯，寫在資料表定義裡

先新增一張集合資料表，再讓片段指向它：

```kotlin
object Collections : IntIdTable("collections") {
    val name = varchar("name", 100)
}

object Snippets : IntIdTable("snippets") {
    val title = varchar("title", 100)
    val collection = reference("collection_id", Collections)
}
```

`reference` 宣告一個外鍵欄位，指向 `Collections` 的主鍵。從這一刻起，資料庫與你的程式碼都知道：每個片段必須屬於一個真實存在的集合。

## 兩個方向的讀取

用 DAO 風格，把兩邊的 Entity 接起來：

```kotlin
class Collection(id: EntityID<Int>) : IntEntity(id) {
    companion object : IntEntityClass<Collection>(Collections)
    var name by Collections.name
    val snippets by Snippet referrersOn Snippets.collection
}

class Snippet(id: EntityID<Int>) : IntEntity(id) {
    companion object : IntEntityClass<Snippet>(Snippets)
    var title by Snippets.title
    var collection by Collection referencedOn Snippets.collection
}
```

從片段取得集合，直接讀 `snippet.collection`。從集合取得底下所有片段，讀 `collection.snippets`。兩邊都有型別保護，拼錯欄位是編譯錯誤。

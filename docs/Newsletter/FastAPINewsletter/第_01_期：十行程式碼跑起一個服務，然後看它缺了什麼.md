# 十行程式碼跑起一個服務，然後看它缺了什麼

文件上那十行程式碼，你貼了，服務也跑起來了，瀏覽器看到 `{"message": "Hello World"}`。然後呢？你不敢改任何一行，因為說不上來每一行在做什麼，也不知道真的專案該長什麼樣子。

這封信就陪你把這十行拆開來看一遍。

## 先看這支 main.py

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
async def root():
    return {"message": "Hello World"}
```

`app = FastAPI()` 建立的是整個服務的主物件。之後所有路由、設定、文件，都掛在這個 `app` 上。

`@app.get("/")` 是一個裝飾器，意思是「有人用 GET 方法請求根路徑時，呼叫下面這個函式」。函式回傳一個 dict，FastAPI 會幫你轉成 JSON 回應，你不用自己序列化，也不用自己設定 `Content-Type`。

這裡有一個容易忽略的事：`FastAPI` 只是一個 Python 套件，本身不會監聽任何 Port。真正負責接網路連線的是另一支程式，也就是 `uvicorn`。

## 啟動指令裡的 main:app

官方文件目前教的啟動方式是：

```bash
fastapi dev
```

執行後，終端會顯示服務跑在 `http://127.0.0.1:8000`，並且程式碼一改就自動重新載入。它底下用的仍然是 `uvicorn`，你可以從輸出的 log 看到。如果你偏好直接叫 `uvicorn`，也行：

```bash
uvicorn main:app --reload
```

`main:app` 的意思是「去 `main` 這個模組，拿名叫 `app` 的物件」，等同於 `from main import app`。所以你把檔案改名成 `server.py`，指令就要跟著改成 `server:app`。`--reload` 只適合開發時用，官方文件明講不要放到正式環境。

安裝的部分，官方文件寫的是 `pip install "fastapi[standard]"`，這一包會連 `uvicorn` 一起帶進來。

## 白送的 /docs

服務跑著的時候，打開 `http://127.0.0.1:8000/docs`，你會看到一頁可以直接點開、填參數、按送出的互動文件。`/redoc` 則是另一種風格的同一份內容。

這兩頁你一行都沒寫。它們是 FastAPI 從路由和型別標註自動產生的，原始資料放在 `/openapi.json`。下一封信起，你會看到型別標註一改，這頁文件也跟著變。

這是你第一次感受到 FastAPI 的取向：把你已經寫下的東西，盡量再利用。

## 它給你的很少

如果你來自 Laravel、Spring Boot 或 Express，這時候大概會下意識地找：資料庫呢？登入呢？`.env` 呢？

FastAPI 只給核心：路由、請求確認、回應序列化、自動文件。其他三樣都得自己選、自己接：

- 沒有內建 ORM，資料庫要自己挑工具。
- 沒有內建認證，登入與保護路由要自己組。
- 沒有內建組態設定管理，不同環境的設定要自己處理。

這是它刻意留下的空間，你可以自己挑喜歡的工具。代價是，這三件事你遲早都得面對，後面幾封信會一件一件補。

## 這封信帶走的東西

`app` 是你的服務本體，`uvicorn` 是接連線的程式，`/docs` 是從路由自動長出來的文件。除此之外，資料庫、認證、設定都要自己補。

路由跑起來了，但如果有人把路徑上的 id 傳成一串英文字，會發生什麼事？下一封信看這件事。

回信告訴我，你現在慣用的是 Laravel、Spring Boot 還是 Express，我想知道你是從哪一邊走過來的。如果這封信是朋友轉給你的，歡迎訂閱，每週一封。

## 待實測項目

以下項目我無法執行程式碼，請在 Python 3.12 與本系列鎖定的 FastAPI 版本實測後再發信：

1. `main.py` 範例需實際啟動，用瀏覽器或 `curl` 確認根路徑回傳 `{"message": "Hello World"}`。
2. `fastapi dev` 與 `uvicorn main:app --reload` 兩種啟動方式都需實測。官方 first-steps 與 deployment 頁面可查到兩者，但稿中「它底下用的仍然是 uvicorn」是依官方 log 輸出推論，需親眼看終端輸出確認。
3. 「`fastapi dev` 預設在 `127.0.0.1:8000` 且自動重新載入」依官方範例輸出，需實測。另外官方現在較推薦在 `pyproject.toml` 設定 `entrypoint`，本稿未提，是否要補一句請裁量。
4. `pip install "fastapi[standard]"` 會帶入 `uvicorn`：官方 deployment 頁面寫的是 `uv add "fastapi[standard]"` 會帶入 `uvicorn[standard]`，pip 版本屬同一 extra 的推論，需在乾淨虛擬環境實測 `pip list`。官方教學頁目前以 `uv add` 為主要示範，稿中是否改寫成 uv 指令，配合系列「uv 管理套件」的設定請裁量。
5. `/redoc` 與 `/openapi.json` 的預設路徑，first-steps 頁面有列，需實際打開確認。
6. 稿中「官方文件明講 `--reload` 不要放到正式環境」依 deployment 頁面，發信當天再看一次原文。
7. 範例路由用 `async def`，與官方範例一致，但第 7 期才會講與 `def` 的差異，確認本期不提不會讓讀者誤解。
